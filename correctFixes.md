## One-Time Setup

### 1. Install CUDA Extensions

```bash
# pointops (required)
cd /home/pi0/POGS-ACT-implementation/POGS/PointCloudMatters/libs/pointops
pip install . --break-system-packages

# spconv for CUDA 11.8
pip install spconv-cu118 --break-system-packages

# torch-scatter (check your torch version first)
python -c "import torch; print(torch.__version__)"
# Replace 2.x.x with your actual torch version e.g. 2.1.0
pip install torch-scatter -f https://data.pyg.org/whl/torch-2.x.x+cu118.html --break-system-packages
```

### 2. Add PointNet++ to PYTHONPATH

```bash
echo 'export PYTHONPATH=/home/pi0/POGS-ACT-implementation/POGS/Pointnet_Pointnet2_pytorch/models:$PYTHONPATH' >> ~/.bashrc
source ~/.bashrc

# Verify
python -c "import pointnet2_utils; print('OK')"
```

### 3. Fix cuDNN library conflict (asr_env interference)

```bash
mkdir -p /home/pi0/miniconda3/envs/pogs_env/etc/conda/activate.d
echo 'export LD_LIBRARY_PATH=/home/pi0/miniconda3/envs/pogs_env/lib:$LD_LIBRARY_PATH' > \
    /home/pi0/miniconda3/envs/pogs_env/etc/conda/activate.d/env_vars.sh

# Reactivate env to apply
conda deactivate && conda activate pogs_env
```

## Data Preparation (Run Once Per Task)

Converts `.npy` RLBench episodes + `shared.ply` POGS scene into `.pkl` files the dataset loader expects.

```bash
cd /home/pi0/POGS-ACT-implementation/POGS/PointCloudMatters

# Train split
python /home/pi0/POGS-ACT-implementation/POGS/POGS/pogs/scripts/convert_npy_to_pogs_pkl.py \
    --npy-dir   data/rlbench/processed/train/open_drawer \
    --ply-path  /home/pi0/POGS-ACT-implementation/POGS/POGS/data/pogs_act/open_drawer/shared.ply \
    --out-dir   /home/pi0/POGS-ACT-implementation/POGS/POGS/data/pogs_act/train/open_drawer \
    --max-points 8192

# Val split
python /home/pi0/POGS-ACT-implementation/POGS/POGS/pogs/scripts/convert_npy_to_pogs_pkl.py \
    --npy-dir   data/rlbench/processed/val/open_drawer \
    --ply-path  /home/pi0/POGS-ACT-implementation/POGS/POGS/data/pogs_act/open_drawer/shared.ply \
    --out-dir   /home/pi0/POGS-ACT-implementation/POGS/POGS/data/pogs_act/val/open_drawer \
    --max-points 8192
```

**Each .pkl episode contains:**
- `tracked_coords`: (T, N, 3) — static point cloud repeated T times
- `tracked_colors`: (T, N, 3) — static colors repeated T times
- `joint_positions`: (T, 7) — gripper pose (xyz + quat)
- `gripper_open`: (T, 1)
- `action`: (T, 11) — 3 pos + 4 quat + 1 gripper + 1 collision + 1 extra
- `variation_id`: int

## Code Changes Applied (All Already Done)

### 1. `configs/exp_rlbench_act_policy/rlbench_model/pogs_pointnet2_act.yaml`
Fully explicit policy spec — avoids inheriting unwanted keys (`pcd_nsample`, `pcd_npoints`, `num_cameras`, `obs_feature_pos_embedding`) from base `rlbench_act_pcd_model`.

### 2. `src/models/components/act/pointnet2_act.py`
- Added `**kwargs` to `__init__` to absorb any extra config keys
- `num_cameras=0` hardcoded (PCD replaces camera images)
- `forward_obs_embed`: handles `pcds` as list → extracts `pcd_dict[0]`
- `_encode_pcd`: fixes DataLoader collation issues:
  - `coord` list → `torch.cat`
  - `feat` list → `torch.cat`
  - `offset` list-of-lists → flatten to 1D tensor before iterating

### 3. `src/models/components/pcd_encoder/pointnet2_encoder.py`
- `_unpack_sparse_dict`: handles both dense `(B, N, 3)` and sparse `(total, 3)` coord formats
- `forward`: handles both dense and sparse offset formats for global feature replication

### 4. `src/data/components/rlbench/pogs_act_dataset.py`
- Fixed `gripper_open` shape: `np.array([gripper_open]).flatten()[:1]`
- Fixed action/qpos slicing: `action_data[..., 7:9]` and `qpos_data[7:9]` to get exactly 2 dims (gripper + collision) after 6d rotation conversion → final shape `3+6+2=11`

## Adding a New Task

1. Capture POGS Gaussian scene → `shared.ply` for the task
2. Collect RLBench demos → `data/rlbench/processed/train/<task>/ep*.npy`
3. Run conversion script pointing to new task dirs
4. Train with `rlbench_task=<new_task>`

## Common Errors & Fixes

| Error | Fix |
|-------|-----|
| `No module named 'pointops'` | `cd libs/pointops && pip install .` |
| `No module named 'spconv'` | `pip install spconv-cu118` |
| `No module named 'pointnet2_utils'` | Add Pointnet2 models dir to PYTHONPATH |
| `Loaded 0 episodes` | `pogs_root` must point to parent of `<task>/` not inside it |
| `pcd_nsample unexpected keyword` | `**kwargs` must be in `__init__` signature |
| `gripper_open dimension mismatch` | Use `np.array([gripper_open]).flatten()[:1]` |
| `Could not override 'key'` | Use `++key=value` for undeclared Hydra keys |
| `offset list-of-lists TypeError` | Flatten offset in `_encode_pcd` before iterating |
| `permute dim mismatch` | `_unpack_sparse_dict` must handle `(B,N,3)` dense coords |
| `Aborted (core dumped) cudnn` | Fix `LD_LIBRARY_PATH` — remove `asr_env` cudnn from path |
| `mat1 and mat2 shapes cannot be multiplied` | action/qpos slice must be `[7:9]` not `[7:]` |

## Model Architecture Summary

```
shared.ply (static POGS Gaussian scene)
        ↓
PointNet2Encoder (pretrained part-seg MSG)
        ↓ (B, 1024) global feature
Linear + LayerNorm projection
        ↓ (B, 512) single observation token
ACT Transformer Decoder
[VAE latent | proprio(11) | obs_token] → (B, chunk_size=100, 11) actions
        ↓
Actions: 3 (pos) + 6 (6d rot) + 1 (gripper) + 1 (collision) = 11 dims
```

**Key design:** POGS `shared.ply` is used as a **static** scene representation —
the same point cloud is used for every timestep in every episode.
No per-frame POGS tracking is needed during training.
